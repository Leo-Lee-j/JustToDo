# JustToDo 功能评估与修复记录

评估日期：2026-11-19。基准：当前 v0.0.7 代码及《JustToDo-PRD.md》的 P0/P1 范围。

## 结论

原版已有桌面窗口、任务 CRUD、提醒、设置和更新基础，但拖拽、编辑入口、多窗口同步和数据写入错误处理尚未形成可靠闭环。本轮优先修复会导致误删、丢失修改、操作无效的问题，并补齐高频操作；当前核心待办流程可用，尚不等于 PRD 全量完成。

## 本轮处理

| 问题 | 修改与验证 |
| --- | --- |
| pnpm 在本机报告 packages field missing or empty | 补充工作区根包声明；本机 pnpm 9 和发布工作流指定的 pnpm 11.17.0 构建均通过 |
| 拖拽引用不存在的手柄，且 v-model 指向只读 getter | 增加实际拖拽手柄，以排序事件提交完整有效 ID 列表；使用真实鼠标拖拽并核对 Rust 写盘结果 |
| 删除 Tab 直接物理删除所属任务 | 改为软删除并记录历史；最后一个 Tab 不可删；被删 Tab 的任务可恢复到仍存在的 Tab |
| 恢复、彻底删除、排序与历史不能完整同步 | 统一 get_app_data 快照与 data:changed 广播，三窗口各订阅一次；写后刷新，另加聚焦与每 60 秒刷新兜底 |
| 重复 load 不断增加事件监听器 | 订阅移到窗口级 store 初始化；刷新请求合并，作用域结束时取消订阅与定时器 |
| JSON 写入吞错，损坏数据可能被默认空数据覆盖 | 原子临时文件写入并同步磁盘；提交成功后才替换内存；读取损坏文件时保留原文件并显示启动错误 |
| 自动备份注释与实现不一致，删除备份可能被覆盖 | 每日首次启动生成数据备份，永久删除前使用唯一文件名备份；每日备份和删除备份各保留最近 14 份；备份失败时阻止删除 |
| 缺少便签搜索与已有任务编辑入口 | 主窗口支持跨 Tab 搜索标题和备注；任务可编辑标题、备注、状态、分类、到期时间和所属 Tab |
| 创建任务备注/优先级需要二次更新，存在重复创建风险 | 创建命令一次提交标题、备注、优先级和日期；可回车或点击添加 |
| 仅能间接通过历史恢复任务 | 增加主窗口和设置中的回收站入口；删除后有 5 秒撤销；彻底删除需二次确认 |
| completedAt 不会在重新打开任务时清空，秒级版本无法可靠识别冲突 | 状态变化维护完成时间；使用高精度 updatedAt；编辑表单保存打开时版本，冲突拒绝并提示 |
| 后台提醒仅每小时扫描，前端另有重复实现 | 后端唯一调度器每 60 秒扫描；日期修改重置去重状态；实际 Windows 通知命令成功，二次扫描返回 0 |
| 快捷键存在未接线与冲突问题 | 接通搜索和打开主界面，保留 Tab 数字切换；录制期间不触发旧快捷键；检测重复及保留组合键 |
| 字体/任务栏显示数量等配置只更新当前窗口 | 保存成功后广播配置变化，各窗口刷新；同一窗口配置写入排队，按最新配置合并 |
| 便签自动收起只有模型字段 | 增加开关及 10/30/60/120 秒延迟；原生窗口收为 200×36，悬停 0.3 秒或点击恢复 360×480；托盘恢复展开 |
| 任务栏窗口高度不足时第三个任务易被裁切 | 改为紧凑任务行，保留直接勾选完成和完整列表入口；按实际物理尺寸定位 |
| 关闭可能销毁常驻窗口、置顶配置未在启动应用 | 关闭事件改为隐藏；启动应用置顶设置；托盘左键唤回；新安装启动位置在主屏工作区右上角 |

## 验证

- 前端：pnpm build 通过；npx --yes pnpm@11.17.0 run build 通过。
- 后端：cargo test --locked --manifest-path src-tauri/Cargo.toml，14 项全部通过。
- Rust 静态检查：cargo clippy --locked --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings 通过。
- Windows 原生应用：使用独立临时数据目录和真实 WebView2，验证新增、Tab 新建/重命名/快捷切换、鼠标拖拽、弹窗编辑同步、备注搜索、删除撤销、Tab 删除后恢复、彻底删除备份、任务栏同步及完成。
- 自动收起：验证实际窗口尺寸、悬停展开、托盘命令展开。
- 通知：后端提交 Windows 通知成功，notifiedAt 写盘，立即再次检查不重复发送。系统最终是否展示横幅仍受 Windows 通知策略控制。
- 布局：在 360×480 的真实窗口中检查主界面与编辑表单，无横向溢出。
- 本轮未对现有用户数据执行测试写入。调试版本可通过 JUSTTODO_DATA_DIR 指向隔离目录；发行版本不启用该覆盖。

| P0 | 更多键盘操作 | 已接通设置中列出的常用组合键；任务选择、Delete、Ctrl+Z、优先级上下调和模式切换等尚未全部实现 |
| P0 | 多显示器与窗口几何持久化 | 边缘吸附和默认右上角可用；尚未完整恢复历史坐标、支持用户调整尺寸或验证混合 DPI/任务栏变更 |
| P1 | 每任务提醒与通知交互 | 使用全局提前小时数；模型中的 reminderTime/reminderEnabled 没有独立 UI 和完整调度；点击通知定位任务、每日过期汇总未实现 |
| P1 | 数据迁移与恢复工具 | 已有旧优先级迁移及文件保护；尚无完整 schema 版本迁移、备份恢复 UI |
| P1 | 单实例体验 | 文件锁可防止多个进程同时写入；第二次启动仍直接退出，尚未唤醒已有实例 |
| P2/P3 | 子任务、附件、看板、主题、统计、导入导出、云同步 | 尚未实现，未在本轮引入 |

签名更新沿用既有实现。本轮未发布版本、上传安装包或执行实际更新安装；开机启动、系统通知策略与混合 DPI 的最终验收仍需在安装版环境验证。
