# JustToDo 功能评估与修复记录

评估日期：2026-11-20（续评）。基准：Windows 桌面便签实现及《JustToDo-PRD.md》的 P0/P1 范围。

## 结论

任务 CRUD、跨窗口同步、可靠写入和 Windows 桌面便签已形成可用闭环。此次补全了备份浏览与恢复、损坏文件启动恢复、重复启动唤回、便签位置恢复、搜索筛选、任务快捷键，以及 Tab 和分类管理。剩余工作主要是通知交互、混合 DPI/显示器切换的原生验收和更高优先级的产品扩展。

## 本轮处理

| 问题 | 修改与验证 |
| --- | --- |
| pnpm 在本机报告 packages field missing or empty | 补充工作区根包声明；本机 pnpm 9 和发布工作流指定的 pnpm 11.17.0 构建均通过 |
| 拖拽引用不存在的手柄，且 v-model 指向只读 getter | 增加实际拖拽手柄，以排序事件提交完整有效 ID 列表；使用真实鼠标拖拽并核对 Rust 写盘结果 |
| 删除 Tab 直接物理删除所属任务 | 改为软删除并记录历史；最后一个 Tab 不可删；被删 Tab 的任务可恢复到仍存在的 Tab |
| 恢复、彻底删除、排序与历史不能完整同步 | 统一 get_app_data 快照与 data:changed 广播，三窗口各订阅一次；写后刷新，另加聚焦与每 60 秒刷新兜底 |
| 重复 load 不断增加事件监听器 | 订阅移到窗口级 store 初始化；刷新请求合并，作用域结束时取消订阅与定时器 |
| JSON 写入吞错，损坏数据可能被默认空数据覆盖 | 原子临时文件写入并同步磁盘；提交成功后才替换内存；读取损坏文件时保留原文件并显示启动错误 |
| 自动备份注释与实现不一致，删除备份可能被覆盖 | 每日首次启动生成数据备份，永久删除前使用唯一文件名备份；每日备份和删除备份各保留最近 14 份；备份失败时阻止删除 |
| 缺少便签搜索与已有任务编辑入口 | 主窗口支持跨 Tab 搜索标题和备注；任务可编辑标题、备注、状态、分类、所属 Tab、到期时间和单独提醒 |
| 创建任务备注/优先级需要二次更新，存在重复创建风险 | 创建命令一次提交标题、备注、优先级和日期；可回车或点击添加 |
| 仅能间接通过历史恢复任务 | 增加主窗口和设置中的回收站入口；删除后有 5 秒撤销；彻底删除需二次确认 |
| completedAt 不会在重新打开任务时清空，秒级版本无法可靠识别冲突 | 状态变化维护完成时间；使用高精度 updatedAt；编辑表单保存打开时版本，冲突拒绝并提示 |
| 后台提醒扫描与任务编辑提醒状态不同步 | 后端唯一调度器每 60 秒扫描；日期和提醒修改重置去重状态；截止提醒与定时提醒共用任务级去重，过期的定时提醒可补发 |
| 快捷键存在未接线与冲突问题 | 接通搜索和打开主界面，保留 Tab 数字切换；录制期间不触发旧快捷键；检测重复及保留组合键 |
| 字体/任务栏显示数量等配置只更新当前窗口 | 保存成功后广播配置变化，各窗口刷新；同一窗口配置写入排队，按最新配置合并 |
| 便签自动收起只有模型字段 | 增加开关及 10/30/60/120 秒延迟；原生窗口收为 200×36，悬停 0.3 秒或点击恢复 360×480；托盘恢复展开 |
| 原右下角摘要浮窗显示任务有限且重复主界面信息 | 移除常驻浮窗；完整任务列表按需从托盘打开，减少桌面遮挡 |
| 关闭可能销毁便签，主便签以独立窗口浮动 | 关闭改为隐藏。主便签启动时挂到桌面右上角，按 Win+D 或使用托盘入口可回到桌面操作 |
| 单任务提醒字段此前没有实际功能 | 任务编辑可设定独立时间；后台一分钟扫描、过期补发、修改后重置去重；增加旧数据兼容 |
| 任务删除撤销缺少键盘操作 | 增加 5 秒内 Ctrl+Z 撤销最近一组删除；文本输入控件保留自身撤销行为 |
| 搜索结果不能快速缩小范围，任务操作依赖鼠标 | 搜索新增状态、分类和优先级筛选；长按任务进入多选，可用 Delete 删除、Ctrl+Enter 完成、Ctrl+方向键调整优先级 |
| Tab 和分类元数据缺少管理界面 | Tab 可改名称和颜色、置顶、拖动排序；设置中可新增/编辑/改色/删除分类，删除时将关联任务转到其他分类；拒绝重复名称和最后一个分类删除 |
| 备份只能由文件系统手动恢复 | 设置页展示有效任务备份并支持二次确认恢复；恢复前先保存当前数据。启动遇到损坏任务或设置文件时可恢复可用备份，保留损坏文件副本 |
| 主便签位置在重启后丢失，重复启动无法唤回 | 保存拖动后的物理坐标，启动时映射到可用显示器工作区；第二个进程通过激活信号唤醒已有便签 |

## 验证

- 前端：`pnpm build` 通过。
- 后端：`cargo test --locked --manifest-path src-tauri/Cargo.toml`，24 项测试全部通过。
- Rust 格式和静态检查：`cargo fmt --check`、`cargo clippy --locked --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings` 通过。
- 差异检查：`git diff --check` 通过。
- 数据恢复测试覆盖损坏文件保留、恢复前快照、无效备份路径和设置单独恢复；Tab 排序、分类删除与提醒去重有回归测试。
- Windows 原生界面复测：本轮待完成；开机启动、Windows 通知策略、桌面挂件和混合 DPI/多显示器仍需在目标安装环境最终验收。
- 本轮未对现有用户数据执行测试写入；隔离测试可通过 `JUSTTODO_DATA_DIR` 指向独立数据目录。
